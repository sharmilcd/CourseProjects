| [MultiClientChatSystem](MultiClientChatSystem) | Multi-client chat over a custom TCP protocol, with fork-, thread- and epoll-based servers benchmarked against each other | C |

| [LibraryManagementSystem](LibraryManagementSystem.cpp) | Library catalogue and lending system | C++ |
